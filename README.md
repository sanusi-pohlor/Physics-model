## ✨ ฟีเจอร์หลัก (5-Pillar Learning Workspace)

1. **พื้นที่จำลอง 3 มิติเชิงโต้ตอบ (3D Interactive Viewport)**
   * หมุน ซูม และแพนมุมมองได้ 360 องศา ด้วย `Three.js` และ `OrbitControls`
   * ปุ่มสลับมุมมองมาตรฐาน (`3D Iso`, `ด้านข้าง`, `มุมสูง`, `ด้านหน้า`) และโหมด **ผ่าโมเดล 3 มิติ (Cross-Section Mode)**
   * แสดงลูกศรเวกเตอร์ 3 มิติ ($\vec{v}, \vec{a}, \vec{F}, \vec{N}, \vec{f}, \vec{\tau}, \vec{E}, \vec{B}$) ที่ยืด-หดและเปลี่ยนทิศทางตามค่าตัวแปรจริง
2. **แผงควบคุมตัวแปรและการเวลา (Parameter & Time Controls)**
   * ปรับค่าตัวแปรทางฟิสิกส์ผ่าน Slider แล้วเห็นผลลัพธ์ในฉาก 3 มิติทันที
   * ควบคุมความเร็วเวลา: `Play / Pause`, `Slow Motion (0.25x, 0.5x)`, `Normal (1x)`, `Fast (2x)` และปุ่มรีเซ็ตค่าเริ่มต้น
3. **สมการฟิสิกส์ไดนามิกและกราฟเรียลไทม์ (Dynamic Equations & Live Telemetry Chart)**
   * แสดงสูตรฟิสิกส์พร้อมแทนค่าตัวเลขจริงและคำนวณผลลัพธ์แบบเรียลไทม์ด้วย `KaTeX`
   * พล็อตกราฟความสัมพันธ์ของตัวแปรตามเวลาจริงคู่ขนานไปกับการเคลื่อนที่ในฉาก 3D
4. **สรุปทฤษฎีและการประยุกต์ใช้ในชีวิตจริง (Theory & Real-World Engineering)**
   * สรุปหลักการสำคัญเข้าใจง่าย พร้อมจุดสังเกตและตัวอย่างการประยุกต์ใช้ในงานวิศวกรรมและชีวิตประจำวัน
5. **โจทย์ภารกิจท้าทายและมินิควิซท้ายบท (Gamified Lab Missions & Mini-Quiz)**
   * โจทย์ภารกิจเชิงปฏิบัติในแต่ละบทที่ระบบตรวจเงื่อนไขการผ่านภารกิจให้อัตโนมัติเมื่อปรับตัวแปรได้ถูกต้อง พร้อมคำใบ้และควิซพร้อมเฉลยละเอียด

## 📚 สารบัญบทเรียนในระบบ (ครบ 5 หมวด 20 บทเรียน)

### หมวดที่ 1: กลศาสตร์ (Mechanics — ม.4)
* **1.1 การเคลื่อนที่แนวตรง (Linear Motion):** ลู่ทดสอบรถยนต์ไฟฟ้า 3D การคำนวณความเร่งและระยะเบรกหยุดหน้าเส้นชัย
* **1.2 กฎของนิวตันและพื้นเอียง (Newton’s Laws):** กล่องมวลบนพื้นเอียง 3 มิติ พร้อมแผนภาพวัตถุอิสระ 3D ($\vec{N}, m\vec{g}, \vec{f}$) และมุมเอียงวิกฤต
* **1.3 สมดุลกลและโมเมนต์ของแรง (Equilibrium & Torque):** เครนและคานสมดุลโมเมนต์ 3 มิติ ($\sum M_{\text{ทวน}} = \sum M_{\text{ตาม}}$)
* **1.4 งานและกฎการอนุรักษ์พลังงาน (Work & Energy):** รางรถไฟเหาะตีลังกา 3 มิติ ($E_p \leftrightarrow E_k$) และเงื่อนไขความสูงขั้นต่ำ $h_{\min} = 2.5R$
* **1.5 โมเมนตัมและการชน (Momentum & Collisions):** การชนของทรงกลม 3 มิติ ทั้งแบบยืดหยุ่นและไม่ยืดหยุ่นสมบูรณ์
* **1.6 การเคลื่อนที่แบบโปรเจกไทล์ 3 มิติ (3D Projectile):** ปืนใหญ่จำลองวิถีโค้งพาราโบลา 3 มิติ และองค์ประกอบความเร็ว $\vec{v}_x, \vec{v}_y$

### หมวดที่ 2: คลื่น เสียง และแสง (Waves, Sound & Optics — ม.5)
* **2.1 คลื่นกลและถังคลื่น 3 มิติ (3D Ripple Tank):** การแทรกสอดของคลื่นผิวน้ำ 3 มิติจากแหล่งกำเนิดอาพันธ์คู่ แนวบัพและปฏิบัพ
* **2.2 เสียงและการสั่นพ้อง (Sound & Resonance):** ท่อเรโซแนนซ์อนุภาคอากาศ 3 มิติ คลื่นนิ่งเสียง และความถี่ฮาร์มอนิก
* **2.3 แสงเชิงรังสีและเลนส์ 3 มิติ (3D Ray Optics Bench):** ม้านั่งทดลองเลนส์นูน-เลนส์เว้า 3 มิติ และทางเดินรังสีหลักเกิดภาพจริง/ภาพเสมือน
* **2.4 แสงเชิงฟิสิกส์และสลิตคู่ของยัง (Young’s Double Slit):** เลเซอร์ 3 มิติ ผ่านสลิตคู่และลวดลายแถบสว่างแทรกสอดตามความยาวคลื่นแสง (400-700 nm)

### หมวดที่ 3: ไฟฟ้าและแม่เหล็ก (Electricity & Magnetism — ม.5-ม.6)
* **3.1 ไฟฟ้าสถิตและสนามไฟฟ้า 3 มิติ (3D Electrostatics):** กฎของคูลอมบ์และเวกเตอร์สนามไฟฟ้า 3 มิติรอบจุดประจุคู่
* **3.2 วงจรไฟฟ้ากระแสตรง (3D DC Circuit Lab):** โต๊ะต่อวงจรตัวต้านทานอนุกรม/ขนาน 3 มิติ การไหลของประจุไฟฟ้า และกฎของโอห์ม
* **3.3 ประจุในสนามแม่เหล็ก 3 มิติ (3D Lorentz Force & Cyclotron):** อนุภาคมีประจุเคลื่อนที่เป็นเกลียว 3 มิติ (Helix) ภายใต้แรงแม่เหล็ก $\vec{F}_B = q(\vec{v} \times \vec{B})$
* **3.4 การเหนี่ยวนำแม่เหล็กไฟฟ้าและไฟฟ้ากระแสสลับ (Faraday & AC):** ไดนาโมปั่นไฟ 3 มิติ และการสั่นพ้องของวงจร RLC ($X_L = X_C$)

### หมวดที่ 4: ความร้อน ของแข็ง และของไหล (Matter, Heat & Fluids — ม.6)
* **4.1 แก๊สอุดมคติและทฤษฎีจลน์ของแก๊ส 3 มิติ (3D Kinetic Gas):** กระบอกสูบอะตอมแก๊ส 3 มิติ กฎแก๊สอุดมคติ $PV = nRT$ และอัตราเร็ว $v_{\text{rms}}$
* **4.2 ของแข็งและสภาพยืดหยุ่น (3D Tensile & Young’s Modulus):** เครื่องดึงทดสอบความเค้น ($\sigma$) ความเครียด ($\varepsilon$) และค่ามอดูลัสของยัง
* **4.3 พลศาสตร์ของไหลและท่อเวนจูรี 3 มิติ (3D Venturi Tube):** สมการความต่อเนื่อง ($A_1v_1 = A_2v_2$) และสมการแบร์นูลลีในท่อคอคอด 3 มิติ

### หมวดที่ 5: ฟิสิกส์แผนใหม่ (Modern Physics — ม.6)
* **5.1 คลื่นแม่เหล็กไฟฟ้า 3 มิติ (3D Electromagnetic Waves):** การแผ่คลื่นสนามไฟฟ้า $\vec{E}$ ตั้งฉากกับสนามแม่เหล็ก $\vec{B}$ ในอวกาศ 3 มิติ
* **5.2 ฟิสิกส์อะตอมและปรากฏการณ์โฟโตอิเล็กทริก (3D Quantum Atom):** แบบจำลองอะตอมของบอร์ 3 มิติ และการฉายโฟตอนปลดปล่อยโฟโตอิเล็กตรอน
* **5.3 ฟิสิกส์นิวเคลียร์และกัมมันตภาพรังสี 3 มิติ (3D Nuclear Physics):** การสลายตัวตามครึ่งชีวิต $T_{1/2}$ และการสอดแท่งควบคุมโบรอนในเตาปฏิกรณ์นิวเคลียร์

## 🚀 วิธีติดตั้งและรันโปรแกรม

### 1. รันโหมดพัฒนาด้วย Node.js (Vite Dev Server)
```bash
npm install
npm run dev
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

### 2. รันด้วย Docker / Docker Compose
```bash
docker compose up -d --build
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend Framework:** React 18 + TypeScript + Vite
* **3D Rendering Engine:** Three.js (`WebGLRenderer`, `OrbitControls`, `ArrowHelper`, Custom 3D Geometries & Clipping Planes)
* **Mathematical Typesetting:** KaTeX
* **UI & Styling:** Tailwind CSS + Lucide Icons
* **Containerization:** Docker Multi-stage Build (`node:22-alpine` $\rightarrow$ `nginx:alpine`)
